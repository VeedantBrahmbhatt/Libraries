# Model phase

This phase has not begun. The prepared catalog supplies separate title, subject, author, language, and abstract fields plus `semantic_text`. A later phase will choose an open-source multilingual model or a custom approach, build an index under project control, and document model version, cost, storage, and retrieval behavior here. No provider will choose search candidates for the application.

Metadata alone is not a set of query-to-book relevance labels. A trained ranking model needs labeled examples or another justified training method.
