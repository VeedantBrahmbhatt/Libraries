# Project handover

## Current scope

The first session prepared 91,667 DOAB book records from its direct repository export. Code is in `src/libraries_data`; test fixtures are synthetic. The [shared output](https://huggingface.co/datasets/Tox1/LibrariesBookData/commit/daba70f6e6de9f7a5c9a1f830fd255415c6d6bb7) is in `Tox1/LibrariesBookData`, and `HF_TOKEN` is stored as a GitHub Actions repository secret. The [publication run](https://github.com/VeedantBrahmbhatt/Libraries/actions/runs/43653263362) passed.

The second phase added `src/libraries_search`: a pinned multilingual E5 encoder, project-owned SQLite keyword search, exact vector search, and reciprocal-rank fusion. The [four-part cloud run](https://github.com/VeedantBrahmbhatt/Libraries/actions/runs/43682889772) built and smoke-tested an index for all 91,667 books, then [published it to the shared Hugging Face dataset](https://huggingface.co/datasets/Tox1/LibrariesBookData/commit/f54ded49b97a92ca8e5dce0463500043ea2a19a4). The [index manifest](https://huggingface.co/datasets/Tox1/LibrariesBookData/raw/f54ded49b97a92ca8e5dce0463500043ea2a19a4/search/v1/manifest.json) pins the source, model, checksums, and sizes. The [recovery record](Search/parallel-build-plan.md) explains the earlier single-runner timeout and parallel design. The README is the current entry point and must be updated with every later project phase.

The third phase adds `src/libraries_evaluation` and a GitHub Actions pilot. It compares all three owned search modes on 12 authored multilingual questions, publishes a small human-review sheet, and scores only a complete judged pool. The full index is used only on a temporary GitHub runner. See the [evaluation runbook](Evaluation/runbook.md) and [phase record](Evaluation/session-log.md). No relevance-quality claim is supported until people grade the returned books.

The [first pilot run](https://github.com/VeedantBrahmbhatt/Libraries/actions/runs/43693270526) passed and produced 233 distinct pairs. The [review artifact](https://github.com/VeedantBrahmbhatt/Libraries/actions/runs/43693270526/artifacts/14153335931) expires on 2026-12-15. No human grades exist yet. A `pyproject.toml` change also reran the catalog publisher; [that run](https://github.com/VeedantBrahmbhatt/Libraries/actions/runs/43693270595) passed with 91,667 books, while the pilot remains pinned to its earlier index revision.

The handoff saves the 233 ungraded pairs as [12 question files](../evaluation/review/pilot/README.md) in GitHub. The lightweight progress check accepts partial grading and rejects changed candidate rows. The full index is downloaded only when the cloud evaluation workflow is run. See the [question collection guide](Evaluation/question-collection.md) for the separate, larger study. Human grades and natural student questions still have to come from people; the AI diagnostic cannot fill that requirement.

The [verified handoff run](https://github.com/VeedantBrahmbhatt/Libraries/actions/runs/43694776677) confirmed the shared sheets match a fresh pinned-index search: 233 pairs, 0 human-graded, 233 remaining. Its [artifact](https://github.com/VeedantBrahmbhatt/Libraries/actions/runs/43694776677/artifacts/14153787137) is temporary; the sheets are in GitHub. The [lightweight progress job](https://github.com/VeedantBrahmbhatt/Libraries/actions/runs/43694776584) passed.

The fourth phase added the [answer-derived diagnostic](Evaluation/answer-derived-results.md). It grades the original 233 pairs separately with AI from short metadata and tests 24 questions written from known source books. The [cloud run](https://github.com/VeedantBrahmbhatt/Libraries/actions/runs/43775201104) used temporary runner storage and the same pinned index. Its [small artifact](https://github.com/VeedantBrahmbhatt/Libraries/actions/runs/43775201104/artifacts/14186206397) expires on 2026-12-15; [pilot metrics](../evaluation/ai-review/pilot-metrics.json) and [source-book recovery metrics](../evaluation/diagnostics/answer-derived-metrics.json) remain in Git. Semantic ranking did better than the current hybrid ranking on both checks. These are useful development findings, not an official KPI pass. The next team action is still to grade the 12 human review sheets, collect 100–150 natural anonymous questions, and test any ranking change on a held-out group.

The fifth phase added [50 fictional student scenarios](../evaluation/personas/README.md) with distinct majors, study goals, and reading needs. The [cloud run](https://github.com/VeedantBrahmbhatt/Libraries/actions/runs/43776657495) searched all three modes without placing the full index on a laptop. Its compact artifact and the 599 assistant grades are saved in Git. The [results](Evaluation/persona-results.md) find a clear top-five fit for 11/50 keyword, 14/50 semantic, and 15/50 hybrid requests. Hybrid narrowly leads on this set, while semantic has more suitable rank-one books and is faster. Many results match the topic without clearly matching the student's level or practical need. These authored scenarios do not replace natural student questions or human judgments.

The sixth phase followed the user's first five improvement steps on branch `improve-query-fit-and-catalog-coverage`. The [miss audit](../evaluation/personas/miss-audit.json) classifies 15 hybrid successes, four known ranking losses, 12 unclear reading-fit cases, and 19 questions without a strong topic match in the judged pool. A cloud audit found 10,598 source-provided alternate descriptions for books missing a primary abstract. The [v2 index upgrade](https://github.com/VeedantBrahmbhatt/Libraries/actions/runs/43781216697) used those descriptions and alternate titles, preserved the 91,667-book order and existing vectors, and published [search/v2 at pinned commit `b745902`](https://huggingface.co/datasets/Tox1/LibrariesBookData/tree/b745902168aca10589fd0b376b58eb8019291b37/search/v2). An explicit-needs parser and optional multilingual second-pass ranker were added. The [50-query cloud diagnostic](https://github.com/VeedantBrahmbhatt/Libraries/actions/runs/43781681831) left new pairs unjudged and measured a reranked p95 of about 7.5 seconds, so this mode is not a UI default. A separate [1,915-textbook coverage pilot](https://github.com/VeedantBrahmbhatt/Libraries/actions/runs/43782166940) did not mix that source into DOAB. Its missing language metadata, weak results, and unresolved duplicates require review. See the [full report](Evaluation/query-fit-results.md) and [runbook](Evaluation/query-fit-runbook.md).

## How to continue

1. Read the [data preparation design](Data-Preparation/design.md), [field dictionary](Data-Preparation/data-dictionary.md), and [runbook](Data-Preparation/runbook.md).
2. Check the [preparation record](Data-Preparation/session-log.md), [search record](Search/session-log.md), [evaluation record](Evaluation/session-log.md), and relevant GitHub Actions runs before claiming that a dataset, index, or evaluation output was published.
3. Start later work on a purpose-named branch, add tests and documentation for that phase, and update the root README.
4. Follow the [search runbook](Search/runbook.md) to query or rebuild the owned search index in a remote environment. The source dataset itself does not provide our search API or ranking.
5. Follow the [evaluation runbook](Evaluation/runbook.md) to judge the original v1 pilot sheets, then collect a **new, frozen v2 candidate pool** from 100–150 anonymous natural questions for v2 human ratings. Do not repoint the v1 collector or reuse old sheet IDs as v2 judgments. Keep assistant grades in `evaluation/ai-review/` and `evaluation/personas/` separate from human grades in `evaluation/review/pilot/`.
6. Use the new [query-fit report](Evaluation/query-fit-results.md) to review the 50-query misses, v2 metadata gain, slow experimental reranker, and textbook candidates. Do not call the 17 known-good hybrid v2 searches or 15 known-good reranked searches final success rates: new pairs are unjudged.
7. After human ratings and a held-out retest, build a five-result interface with at most ten after “More options,” grounded summaries, source links, and a free interactive backend. GitHub Pages alone cannot run the Python models or index. Real student login and profiles remain outside this prototype's approved scope.

## Boundaries to preserve

The prototype has no real student login or profiles. Do not add paid infrastructure, raw DOAB files to Git, or secrets to code. Keep book licenses distinct from the CC0 metadata license. Avoid presenting uncalibrated ranking numbers as confidence probabilities.

DOAB's website advertises over 111,000 books, while its direct export yielded 91,667 books on 2026-11-14. Investigate this gap before claiming full live-site coverage. The 90,000-book publication gate guards against a major drop in export size, not every possible missing record.
